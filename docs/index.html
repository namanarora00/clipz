Features

Everything you copied. Findable.

One clipboard slot is not a personality. Clipz keeps the whole history, the context around it, and a way back to where it came from.

Remembers the source

Browser URLs, editor files, the app you copied from. Jump back to the page instead of opening a tab and saying "good luck".

Search by meaning

Type "flight booking" and find the boarding pass. EmbeddingGemma 2 runs inside the daemon, so semantic search needs no Ollama and no internet.

Ask your clipboard

"What was I working on today?" Hit ⌘ ↵ and get an answer with sources. Use Raycast AI, local Ollama, OpenAI or Anthropic.

Hides obvious secrets

API keys, tokens, JWTs, private keys and env vars get flagged and masked before you demo your screen like a genius. Best effort: a seatbelt, not a vault.

Optional iCloud sync

Turn it on and your history (and its search index) follows you across Macs. Turn it off and it stays in ~/.clipz.

No artificial limits

Your real limits are disk space, SQLite, and your tolerance for preserving everything you copied at 2 AM "for later".

Ask AI · ⌘↵

Ask your clipboard. It shows its sources.

Hit ⌘ ↵ and ask about your history in plain words. You get a short answer and the clips it came from, so you can check its homework.

Under the hood

How it works

A tiny Swift daemon watches the clipboard and does the heavy lifting. Raycast is just the window you look through.

01 · You

Copy something

  • Text, links, code
  • From any app
  • Password managers skipped
02 · clipz-daemon

Swift, always on

  • Detects secrets & type
  • Grabs URL / file context
  • Embeds it with EmbeddingGemma 2
03 · SQLite

history.db

  • Clips + metadata
  • 768-dim vectors
  • Local or iCloud Drive
04 · Raycast

Search & ask

  • Text + semantic matches
  • Paste, copy, open source
  • Ask AI with sources
~10 msper semantic search
~165 MBdaemon memory at idle
~300 MBone-time model download
0Clipz servers, forever

Embedded the moment you copy

The daemon runs Google's EmbeddingGemma 2 through llama.cpp with Metal. Every new clip becomes a vector right away, and anything synced from another Mac is picked up within a minute. Search never waits on a backlog.

Only the matches that stand out

Raycast sends your query over a private Unix socket. The daemon scores every clip and keeps just the ones well above that query's own baseline, so unrelated stuff stays out of the way. Plain text matches still show up underneath.

  • History stays on your Mac, in ~/.clipz/history.db, unless you turn on iCloud sync.
  • Semantic search is fully local. The model runs in the daemon; your clips never leave the machine to get embedded.
  • Sensitive clips are never embedded and are masked in the UI.
  • Ask AI uses the provider you pick. Local Ollama keeps it on-device. Raycast AI, OpenAI or Anthropic will receive the clips needed to answer.
Install

Up and running in three commands

Ridiculous amount of ceremony for remembering text, but here we are.

~/code 
$ git clone https://github.com/namanarora00/clipz
$ cd clipz && npm run setup
$ npm run dev   # loads the extension into Raycast
  • NeedsmacOS with Raycast, and Xcode command line tools for the Swift compiler.
  • InstallsNode deps, the clipboard daemon, the EmbeddingGemma 2 model, and Ollama for local Ask AI.
  • PermissionsmacOS may ask for Accessibility or Automation access so Clipz can see where you copied from. Naturally.
